# Cyberster Blue Team Internship

## 📌 Overview
This repository documents my work during the **Cyberster Blue Team Internship**, focusing on cybersecurity, cloud security, and compliance frameworks.  
It includes weekly tasks, reports, and capstone projects covering threat detection, digital forensics, and incident response.
